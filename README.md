# Luna Overlay

Erste Testversion für Android.

Ziel:
- Luna als Overlay über anderen Apps anzeigen.
- Version 0.1 zeigt zunächst einen einfachen Luna-Platzhalter.
- Später werden die Zustände Warten, Zuhören, Arbeiten und Antworten durch Animationen ersetzt.

Die APK wird automatisch über GitHub Actions gebaut.
